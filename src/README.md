🚀 Landing Page Reparo Pronto: Moderna e Responsiva

Uma landing page desenvolvida com foco em conversão, performance e experiência do usuário, simulando um cenário real de captação de leads para serviços.

---

📌 Sobre o projeto

Este projeto foi criado com o objetivo de construir uma página estratégica, clara e funcional, capaz de guiar o usuário até a ação, utilizando boas práticas de UI/UX e estrutura de conversão.

A proposta foi desenvolver uma interface moderna, intuitiva e responsiva, com boa adaptacao para diferentes tamanhos de telas, incluindo dispositivos moveis.

---

🎯 Objetivos

- Apresentar serviços de forma clara e objetiva
- Gerar confiança através de elementos visuais e sociais
- Direcionar o usuário para contato (WhatsApp)
- Simular um projeto real de mercado

---

🧩 Funcionalidades

- ✅ Hero com chamada principal e call-to-action
- ✅ Seção de serviços com cards reutilizáveis
- ✅ Seção de confiança (Trust)
- ✅ Etapas do processo ("Como funciona")
- ✅ Depoimentos de clientes (Testimonials)
- ✅ Perguntas frequentes (FAQ)
- ✅ Footer com CTA final
- ✅ Botões de contato integrados (WhatsApp)
- ✅ Animações suaves ao scroll (reveal)
- ✅ Layout totalmente responsivo

---

🛠️ Tecnologias utilizadas

- React
- JavaScript (ES6+)
- CSS3 (Flexbox e Grid)
- React Icons

---

🧠 Arquitetura e boas práticas

- Componentização para reutilização de UI
- Uso de props para flexibilidade dos componentes
- Organização por seções (Hero, Services, Trust, etc.)
- Código limpo e de fácil manutenção
